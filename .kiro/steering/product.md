# Product Context

AIAS is a Python project whose repository documents computer-vision processing, a Flask-based local dashboard, configuration/logging modules, and a serial-connected microcontroller/firmware component.

For engineering tasks covered by this steering set, prioritize:
- software correctness and maintainability;
- reliable lifecycle and resource cleanup;
- reproducible offline image-processing tests;
- observable performance measurements and useful logs;
- reliable, documented serial-device diagnostics;
- safe, incremental development with regression tests.

Do not expand the project into automated aiming, recoil-control automation, humanized game-input behavior, or anti-cheat evasion. Do not optimize game-player targeting. Keep work within general-purpose software quality, offline computer-vision validation, and hardware reliability.
